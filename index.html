How to Password Protect a PDF on Mac Using Preview — Free

Whether you need to stop unauthorized viewing or prevent copying and printing, macOS gives you built-in tools to secure your documents. Here is the complete guide to locking PDFs on your MacBook or iMac.

Editorial Team · Updated Oct 2023 · 8 min read
Quick Answer

To quickly password protect a PDF on a Mac for free: Open the PDF in the native Preview app. Go to File > Export. Check the Encrypt box, enter your desired password, verify it, and click Save. The newly saved file will now require a password to open on any device.

Permissions Password vs Open Password — Explained

Before you lock your document, it is crucial to understand that macOS and PDF standards recognize two completely different types of passwords. Applying the wrong one means your data isn't as secure as you think.

The Open Password (Document Open Password)

This is full encryption. When you apply an open password, the actual contents of the PDF are mathematically scrambled. Nobody can see the text, images, or metadata without entering the correct password. This is the standard you should use when emailing sensitive financial documents or personal records.

If you need to stop someone from reading the file entirely, you must use an Open Password. This is the only way to encrypt the data.

The Permissions Password (Master Password)

A permissions password restricts actions, not access. The recipient can open and read the PDF without typing a password. However, if they try to print it, copy text, or edit the document, they will be prompted for the password. Warning: Permissions passwords do not encrypt the document, and many third-party PDF readers routinely ignore these restrictions.

Password Protect PDF on Mac — 3 Free Methods

You do not need to purchase expensive software to secure a PDF file on Mac. macOS Ventura, Sonoma, and Sequoia all include native tools to handle basic encryption.

Method 1: How to Password Protect a PDF on Mac Using Preview

The easiest method requires no extra software. The built-in macOS Preview app can apply strong AES-128 encryption to any PDF.

  1. Double-click your PDF to open it in Preview.
  2. In the top menu bar, click File and select Export. (Do not select "Export as PDF").
  3. In the dialog box, look for the Encrypt checkbox near the bottom and check it.
  4. Enter your password in the Password field and re-type it in the Verify field.
  5. Click Save.

Note on compatibility: This applies an Open Password. The resulting file can be opened on Windows, Android, or iOS, provided the recipient has the password and a standard PDF reader.

Method 2: How to Password Protect a Document from Pages or Keynote

If you are creating the document natively on your Mac, you can lock it before it even becomes a PDF.

  1. Open your document in Apple Pages, Numbers, or Keynote.
  2. Click File > Set Password.
  3. Enter and verify your password.
  4. To share it as a PDF, go to File > Export To > PDF. The PDF will automatically inherit the password protection.

Method 3: Remove PDF Password on Mac Using Preview

If you have an encrypted PDF and want to save an unprotected version for easier access in the future:

  1. Open the encrypted PDF in Preview and enter the password.
  2. Click File > Export.
  3. Uncheck the Encrypt box.
  4. Save the file with a new name. The new file will no longer require a password.

Security Warning: You cannot bypass a password this way. You must know the original password to open the file before you can remove the encryption.

Troubleshooting & Recovery

Working with encrypted PDFs occasionally leads to lockouts or compatibility issues. Here is how to resolve the most common problems.

How to unlock a PDF you forgot the password to on Mac?

If you applied an Open Password via macOS Preview and forgot it, the file cannot be natively recovered. macOS does not save a "backdoor" key. You must either find the password in your Keychain (if you saved it), request an unprotected copy from the original sender, or restore an older, unencrypted version of the file using Time Machine.

Why can Google Chrome open my password-protected PDF without a password?

If Chrome opens the file without prompting for a password, it means you only applied a Permissions Password, not an Open Password. As explained earlier, Permissions passwords only restrict editing/printing, not viewing. Furthermore, Chrome's built-in PDF viewer notoriously ignores Permissions passwords, allowing users to print or copy text anyway.

Can I batch password protect multiple documents at once?

Not natively using Preview. If you have dozens of files, you have to open and export them one by one. To lock multiple files, you must use Mac's Disk Utility to create an encrypted `.dmg` container, or use dedicated third-party document security software.

Frequently Asked Questions

How to password protect a PDF on Mac without Adobe?

You can use the built-in macOS Preview app. Open your PDF, select File > Export, check the "Encrypt" box, and enter your password. No third-party software like Adobe Acrobat is required.

Can I remove the password protection from a PDF?

Yes, provided you know the password. Open the PDF in Preview, enter the password to unlock it, go to File > Export, uncheck the "Encrypt" box, and save it as a new file.

What encryption level does macOS Preview use for PDFs?

Modern macOS versions (Ventura, Sonoma, Sequoia) use strong AES-128 encryption when you apply an Open Password via Preview. This is secure enough for most personal and business documents.

How to share a password-protected PDF safely?

If you use Preview, never send the password in the same email or message as the document. For ultimate safety, use a tool like Folder Lock that allows you to authorize recipients without needing to hand off a password at all.

Can a password-protected document be hacked?

If you use an Open Password with strong encryption (AES-128 or AES-256) and a long, complex password, it is practically unhackable. However, if you use a simple dictionary word, it can be cracked using brute-force tools.

Is PDF password protection the same as encryption?

An "Open Password" utilizes true encryption (scrambling the file data). A "Permissions Password" does not encrypt the file; it merely sets a flag asking the PDF reader program not to allow printing or editing.
